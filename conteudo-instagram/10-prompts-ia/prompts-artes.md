# Prompts de IA para as Artes — Lucas Limpa Nome

Prompts em inglês (rendem melhor em Midjourney/DALL·E/Higgsfield/Ideogram) para
gerar **fundos e cenas premium** no padrão da marca. Regra de ouro: a **IA gera o
fundo/cena; o texto você coloca por cima no Canva** (IA erra texto em português).

## Bloco fixo de estilo (cole no fim de todo prompt)

```
premium fintech brand aesthetic, deep navy blue (#0a1f3c) and emerald green
(#10b981) palette, clean minimalist composition, lots of negative space, subtle
dot-grid texture, soft radial glow, glassmorphism UI cards, cinematic soft
lighting, high-end editorial look, 4k, sharp, no text, no logo, no watermark
```

## Negativos (quando o modelo aceitar `--no` / negative prompt)

```
--no text, watermark, logo, clutter, rainbow gradient, stock-photo cliché,
handshake, flying money, clip art, low quality, distorted, busy background
```

---

## 1. Fundo — Capa de autoridade (navy)
```
Vertical 9:16 premium fintech background, deep navy gradient with a very subtle
dot grid, a soft emerald glow in the upper center, floating translucent glass
cards, tiny light particles, cinematic depth of field, empty clean space for
text overlay. [+ bloco de estilo]
```

## 2. Fundo — Educação (claro)
```
Vertical 4:5 clean light background, off-white with a faint blue tint (#f4f7fb),
one minimalist emerald-green line icon motif, generous margins, soft shadow,
airy and premium like a Stripe or Linear illustration, space for text.
[+ bloco de estilo]
```

## 3. Cena — Velocímetro / índice de saúde financeira
```
A sleek semicircular gauge/speedometer UI, arc from red to amber to green, needle
pointing toward green, bold number below, floating as a glass card over a deep
navy background with soft glow, premium 3D render, clean. [+ bloco de estilo]
```

## 4. Cena — Pessoa real (UGC premium, sem clichê)
```
Authentic candid portrait of a Brazilian adult (30s–40s) looking relaxed and
hopeful while checking a smartphone at home in soft daylight, natural skin, not a
stock-photo pose, shallow depth of field, warm realistic lighting, navy-and-green
color grade, editorial documentary style. [+ bloco de estilo]
```

## 5. Cena — "Antes e depois" (split)
```
Split composition, left half dark navy with a subtle downward line, right half
light and airy with an upward emerald line, minimalist metaphor of organization
and clarity, no text, premium editorial. [+ bloco de estilo]
```

## 6. Textura — Padrão de fundo para stories
```
Seamless subtle dot-grid pattern in navy tones with faint emerald accents, very
low contrast, premium tech texture, minimal, for background use. [+ bloco de estilo]
```

---

## Fluxo recomendado

1. Gere 3–4 variações do fundo.
2. Faça upscale da melhor (2K/4K).
3. Leve pro Canva, aplique o Design System (texto, logo, CTA).
4. Exporte 1080×1350 (feed) ou 1080×1920 (stories/reels).

## Compliance nas artes de IA

Nunca gere imagem que simule tela real de Serasa/Banco Central, comprovante
oficial, ou "nome limpo aprovado". Cena é **conceitual/ilustrativa**, sempre.
